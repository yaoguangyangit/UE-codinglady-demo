四、全局规则

  • 演示模式：默认固化预处理结果（31+6 件衣物 / 21 张照片），?live=1 实时 GLM
  • 诚实红线：故事只用元数据，无地点/人物不编造；尺码靠推演不靠照片猜
  • 状态机：在役 / 临近退役（差 1 档）/ 已退役（差 ≥2 档）/ 闲置（只穿 1 次）
  • 弹层统一 portal；图片统一 onError 回落 SVG；照片本体不进 git 仓库
